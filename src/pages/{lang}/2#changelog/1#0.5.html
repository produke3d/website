Greetings dukers, v0.5 is now released! This version has 2 main features: Spectator mode and the Freecam mode (to be used with Spectator or with the Demo Viewer). There's finally a fix for players using duplicated duke colors now. There are other improvements and bug fixes too. Saudações dukais a todos, a v0.5 está lançada! Essa versão possui 2 novas funcionalidades principais: modo espectador e o modo de câmera livre (para ser usado com o modo espectador ou com o visualizador de demos). Finalmente há uma solução para evitar o uso de cores do duke duplicadas agora. Há também outras melhorias como também correções de bugs.

New Features Novas Funcionalidades

  • Now there's a spectator mode in proDuke. It can be acessed on the MAIN MENU: O proDuke agora possui o modo espectador. Ele pode ser acessado pelo menu principal:
    • If you're currently an active player, the option will be named SPECTATE GAME, and entering it will give you the option to: (Y/ENTER) enter the spectator mode immediatelly (which will kill you and result in a -1, in case you're alive); (D) postpone it until your next DEATH, or (M) postpone it until the next MATCH.
    • If you're currently already spectating, the option will be named JOIN GAME, and entering it will give you the option to: (Y/ENTER) join the match immediatelly; or (M) postpone it until the next match.
    • If you have a postponed transition queued, the option will be named ABORT SPEC SWITCH, which will allow you to undo the postponing. Also, a icon will be displayed on your HUD, on the lower left side of the screen, to better signal that.
    • There are options to disable the freely going and leaving to spectator. More on that later.
    • Se você atualmente está em jogo, a opção terá nome de SPECTATE GAME, e ao entrar nela será apresentada as opções: (Y/ENTER) entrar no modo espectador imediatamente (o que irá lhe matar e resultar em -1, caso você esteja vivo); (D) postergar para sua próxima morte; ou (M) postergar para a próxima partida.
    • Se você atualmente já é espectador, a opção terá nome de JOIN GAME, e ao entrar nela será apresentada as opções: (Y/ENTER) entrar na partida imediatamente; ou (M) postergar para a próxima partida.
    • Se você já possui uma transição postergada, a opção terá nome de ABORT SPEC SWITCH, que permitirá você desfazer o postergamento. Além disso, um ícone será exibido no HUD, no lado inferior esquerdo da tela, para deixar isso claro.
    • Existem opções para limitar essas idas e vindas ao modo espectador. Veremos mais sobre isso posteriomente.

    • The 
      OPTIONS > GAME OPTIONS > DISABLE PLAYER COLORS [ON/OFF]
      option was redesigned into 
      PLAYER COLORS [CLASSIC/FORCE UNIQUE/UNRESTRICTED]
      . Remember that this is still a local setting, so player colors may b different for different users. The options now behave as follows:
      • CLASSIC: forces the default sequential colors on everyone. This is the option for players that dislike the new colors.
      • FORCE UNIQUE: players with custom colors have priority on the color slots. In case of a duplication, the player with the smaller ID have preference. The rest of the players (the ones who did not picked a color + the ones with a duplicated color but with higher player ID) will get the remaining colors, in sequential order.
      • UNRESTRICTED: like the above, but it allows duplicated colors. Players with color set to AUTO will still receive unused colors.
       A opção 
      OPTIONS > GAME OPTIONS > DISABLE PLAYER COLORS [ON/OFF]
      foi modificada para ser 
      PLAYER COLORS [CLASSIC/FORCE UNIQUE/UNRESTRICTED]
      . Lembre-se de que essa é uma opção local, então as cores dos jogadores podem ser diferentes para diferentes usuários. As opções agora são a seguir:
      • CLASSIC: força as cores padrões sequencias para todos. Esta é a opção para os jogadores que não gostam de cores customizadas.
      • FORCE UNIQUE: jogadores que optaram por utilizar cores customizadas terão prioridade nos slots de cores. Em caso de duplicação, o jogador com o menor ID terá preferência. O resto dos jogadores (quem não escolher uma cor + quem escolheu duplicata e possui ID maior) receberá as cores restantes, em ordem sequencial.
      • UNRESTRICTED: como a anterior, mas cores duplicadas são permitidas. Jogadores que deixarem sua cor setada como AUTO ainda receberão cores não utilizadas.
