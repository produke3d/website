You can send a message to only your team or to a specific player. Você pode mandar uma mensagem para apenas o seu time ou para um jogador especifico.
In proDuke you can now specify the recipients using shortcuts: No proDuke você pode especificar o destinatário por meio de atalhos:
SHORTCUT ATALHO DESCRIPTION DESCRIÇÃO
* Send the message to everyone. Example:
Typing 
*proDuke is the future
will send the message proDuke is the future to everyone. Envia a mensagem para todos. Exemplo:
Digitar 
*proDuke eh o futuro
enviará a mensagem proDuke eh o futuro para todos.
# Sends the message only to your team. Example:
Typing 
#CTF is amazing!
will send the message CTF is amazing! to your team allies. Envia a mensagem apenas para o seu time. Exemplo:
Digitar 
#CTF eh dahora!
enviará a mensagem CTF eh dahora! para todos do seu time.
$ Sends the message only to spectators. Example:
Typing 
$Spectator mode rocks!
will send the message Spectator mode rocks! to all spectators. Envia a mensagem apenas para espectadores. Exemplo:
Digitar 
$Modo espectador ta foda!
enviará a mensagem Modo espectador ta foda! para todos espectadores.
! Sends the message only to non-spectators. Example:
Typing 
!Spectator mode rocks!
will send the message Spectator mode rocks! to all non-spectators. Envia a mensagem apenas para quem estiver em jogo (não-espectadores). Exemplo:
Digitar 
!Modo espectador ta foda!
enviará a mensagem Modo espectador ta foda! para todos não-espectadores.
@P Send the message only to player P, where P is the player number. Example:
Typing 
@3You suck!
will send the message You suck! to the player 3 (the player order is the same on the score bars, counting from 1 onwards). Envia a mensagem apenas para o jogar P, onde P é o número do jogador. Exemplo:
Digitar 
@3Tu eh ruim!
enviará a mensagem Tu eh ruim! para o player 3 (a ordem dos players é a mesma da barra de pontuação, com a contagem começando em 1).
You can change the chat behavior to a Simplified mode on 
OPTIONS > GAME OPTIONS > SIMPLIFIED CHAT
. Você pode mudar o comportamento do chat para o modo simplificado em 
OPTIONS > GAME OPTIONS > SIMPLIFIED CHAT
.
OPTION OPÇÃO DESCRIPTION DESCRIÇÃO
OFF In this mode, before the message is sent, the game will ask for the message recipient (like in the screenshot above), unless the recipient shortcuts are used. Neste modo, antes que a mensagem seja enviada, o jogo perguntará qual o destinatário da mensagem (como na screenshot acima), a não ser que os atalhos de destinatário sejam usados.
ON In this mode, the game doesn't ask who you want to send the message to, it just sends it to everyone by default. If you want to send a private message to a specific recipient then you'll have to use chat shortcut prefixes. Neste modo, o jogo não pergunta para quem você quer enviar a mensagem, ela será enviada para todos por padrão. Se você quiser enviar uma mensagem privada para um destinatário específico, você precisará utilizar os prefixos de atalho.
