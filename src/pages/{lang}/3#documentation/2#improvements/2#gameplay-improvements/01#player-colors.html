You can choose your color in non-team based modes at the menu 
Options > Player Setup > Color
. You can also set your color using the 
COLOR
console command (e.g. typing 
COLOR 1
or 
COLOR BLUE
will set your color to BLUE). Note that you CANNOT change your color for the current match, a match restart is needed for it to take effect, and that is only if the session is not using Lock Players option. Você pode escolher a sua cor em modos não baseados em times no menu 
Options > Player Setup > Color
. Você também pode setar sua cor pelo commando de console 
COLOR
(e.g. digitar 
COLOR 1
ou 
COLOR BLUE
setará sua cor para AZUL). Note que NÃO é possível trocar a cor para a partida atual, a mudança de cor só ocorrerá ao iniciar uma nova partida, e isso só terá efeitos caso a sessão não esteja usando a opção Travar Jogadores. If you don't care about custom colors, you can leave your own color set to 
Auto
and the game will give you the default automatic sequential color, like in the original game. Se você não liga para cores customizadas, você pode deixar a sua própria cor setada em 
Auto
e o jogo irá lhe dar a cor padrão automatica sequencial, como no jogo original. Or, if you really dislike custom colors, you can force the game to show other players with the default automatic sequential colors by setting 
OPTIONS > GAME OPTIONS > PLAYER COLORS
to 
CLASSIC
. The available optins are: Ou, se a customização de cores lhe desagrada, você pode forçar o jogo a exibir os outros jogadores com as cores automáticas padrões sequencias mundando 
OPTIONS > GAME OPTIONS > PLAYER COLORS
para 
CLASSIC

MODE MODO DESCRIPTION DESCRIÇÃO
CLASSIC Forces the default sequential colors on everyone. This is the option for players that dislike the new colors. Força as cores padrões sequencias para todos. Esta é a opção para os jogadores que não gostam de cores customizadas.
FORCE UNIQUE Players with custom colors have priority on the color slots. In case of a duplication, the player with the smaller ID have preference. The rest of the players (the ones who did not picked a color + the ones with a duplicated color but with higher player ID) will get the remaining colors, in sequential order. Jogadores que optaram por utilizar cores customizadas terão prioridade nos slots de cores. Em caso de duplicação, o jogador com o menor ID terá preferência. O resto dos jogadores (quem não escolher uma cor + quem escolheu duplicata e possui ID maior) receberá as cores restantes, em ordem sequencial.
UNRESTRICTED Like the above, but it allows duplicated colors. Players with color set to AUTO will still receive unused colors. Como a anterior, mas cores duplicadas são permitidas. Jogadores que deixarem sua cor setada como AUTO ainda receberão cores não utilizadas.
